# Dessert Shopping Cart 🍰

A simple, interactive shopping cart application for desserts. Built with vanilla HTML, CSS, and JavaScript, this project demonstrates front-end development concepts like DOM manipulation and state management.

## ✨ Features

- **Browse Desserts:** View a selection of delicious desserts with prices.
- **Add to Cart:** Add items to your shopping cart with a single click.
- **Total Calculation:** Automatically calculates and displays the total price.

## 🛠️ Technologies Used

- **HTML5:** For structuring the web page.
- **CSS3:** For styling and layout (including Flexbox/Grid).
- **JavaScript (ES6+):** For all interactive functionality and logic.

## ⚙️ Installation & Setup

To run this project locally, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/dessert-shopping-cart.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd dessert-shopping-cart
    ```
3.  **Open `index.html` in your browser.**

## 💡 How to Use

1.  Browse the list of available desserts.
2.  Click the "Add to Cart" button on any item.
3.  The total price will update automatically.
